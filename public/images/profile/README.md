La photo de profil extraite du CV fourni se trouve dans `prince-ahou.jpg`.
Le chemin public correspondant est défini dans `src/data/profile.js` :

```js
// Le chemin commence à la racine publique du site, pas par C:\\wamp64\\...
photo: '/images/profile/prince-ahou.jpg',
```

Pour changer la photo, remplace ce fichier par une autre image ou mets à jour la propriété `photo`.
