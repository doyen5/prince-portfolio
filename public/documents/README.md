Le CV PDF fourni est inclus dans ce dossier sous le nom `Ahou-Kouame-CV.pdf`.
Le chemin public est centralisé dans `src/data/profile.js` :

```js
// Les boutons de téléchargement du site utilisent ce chemin.
cv: '/documents/Ahou-Kouame-CV.pdf',
```

Pour remplacer le CV, remplace le PDF et garde le même nom, ou mets à jour la propriété `cv`.
