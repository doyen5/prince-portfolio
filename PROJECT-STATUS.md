## Vérification technique

Le projet est livré avec tous les fichiers source et les ressources publiques. L'installation des dépendances a expiré dans l'environnement de préparation ; le build n'a donc pas pu être exécuté ici. Après extraction, lance `npm install`, puis `npm run build`, `npm run lint` et `npm test` sur une machine disposant de l'accès npm.
